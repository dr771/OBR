# Blog

The old site's blog carries about a quarter of all search clicks (12,464 of 42.7k in 16 months), so
it is recreated in Shopify. It does not exist yet: the dev shop only has Shopify's default `news`
blog. The redirects for it are generated by `scripts/build-redirects.js`; see
[SEO-REDIRECTS.md](SEO-REDIRECTS.md).

## URL structure (owner decision 2026-10-01)

Shopify fixes the shape as `/blogs/<blog handle>/<post handle>`. A post directly under `/blogs/` is
not possible. Drupal used `/nl/blog/<category>/<post>`: 19 posts in 14 categories.

- **One blog; the old categories become tags.** Working handle `inspiratie`. If the blog is created
  under another handle, change `BLOG` in `scripts/build-redirects.js`.
- **Post handle = the old last slug segment, unchanged**, so each redirect is mechanical:
  `/nl/blog/hielspoor/fitflop-d-slipper-…` → `/blogs/inspiratie/fitflop-d-slipper-…`.
- **Tag = the old category slug**: `/nl/blog/hielspoor` → `/blogs/inspiratie/tagged/hielspoor`.
  `/nl/blog` → `/blogs/inspiratie`.
- **Blog-like pages that lived outside `/blog/`** become posts under the same rule.

Why not one blog per Drupal category (`/blogs/hielspoor/…`): 14 blogs for 19 posts, 11 of them with
a single post; Shopify has no page listing posts across blogs; every new topic would need a new
blog; and there is no SEO gain, since every post needs a redirect either way.
