# Original Brands — Shopify Theme

Liquid theme for Original Brands, based on [Dawn](https://github.com/Shopify/dawn). Connected to the `original-brands-dev.myshopify.com` development store.

See `MIXED-SHOPS-PLAYBOOK.md` for scoping decisions and reuse notes (shared with the Only Brands project). The pre-Shopify static homepage mockup lives in `mockup/` for reference.

## Local dev

```
shopify theme dev --store=original-brands-dev.myshopify.com
```
