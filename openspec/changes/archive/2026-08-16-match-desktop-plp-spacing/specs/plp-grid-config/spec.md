## ADDED Requirements

### Requirement: Desktop collection grid follows approved spacing
At desktop widths, a vertical-filter collection PLP SHALL use a 2.4rem outer page inset, a 2.4rem horizontal product-card gap, and a 3.6rem vertical product-card gap.

#### Scenario: Four-column collection grid renders on desktop
- **WHEN** the vertical-filter collection PLP renders at 1440px viewport width
- **THEN** its content begins 24px from each page edge, adjacent product cards are separated by 24px horizontally, and successive product rows are separated by 36px vertically
